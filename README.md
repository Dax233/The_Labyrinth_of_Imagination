# The Labyrinth of Imagination

> 用文字在 N 维迷宫里寻找宝藏的小游戏。

原项目由 [Bakadax](https://github.com/Dax233) 于 2024 年用 Python 编写；
本仓库是 2026-11 的结构翻新版本（0.2.0）：玩法、操作指南文案、配置项与难度映射全部保留，
只是把 361 行的单文件拆成了可测试的包。许可证仍为 [AGPL-3.0](LICENSE)。

## 这是什么

一个运行在终端里的 N 维迷宫游戏。迷宫用深度优先搜索生成，每一关你从起点出发，
找到宝藏后再走回起点就能通关。二维迷宫里你只能前进/后退/仰俯转；
三维及以上还会多出左右转（a/d），越高维度越容易迷路（笑）。

## 玩法

每一关的目标：

1. 从起点（`S`，出口）出发；
2. 找到宝藏（`E`）并踩上去；
3. 再回到起点（`S`），通关。

操作指南（与旧版逐字一致）：

```text

  操作指南：
   w[n]——向前n步，当n被省略时默认向前一步。
   q——仰转。
   e——俯转。
   a[n]——左转至n维方向上，当n被省略时默认转向可转向的最低维度。
   d[n]——右转至n维方向上，当n被省略时默认转向可转向的最低维度。
   s——向后转。
   h——打开操作指南。
  r——回到主菜单。
```

- `w` / `w3`：向前 1 步 / 向前最多 3 步，撞墙会停下并提示；
- `q` / `e`：仰转 / 俯转（二维世界里也能用）；
- `a` / `d`：左右转，从三维起可用；`a2` 表示转向第 2 维方向（数字从 1 开始）；
- `s`：向后转；
- `h`：随时打印操作指南；
- `r`：回到主菜单（当前进度作废）。

主菜单还提供「自定义模式」：自己输入维度（2–29）和边长（3–29）。
注意迷宫大小是 `边长 ** 维度` 个格子，数字给大了会非常吃内存和时间。

## 安装与运行

需要 Python 3.9 及以上。**运行时没有第三方依赖**（重构后不再需要 numpy）。

直接从仓库运行：

```bash
python -m labyrinth
```

或者安装成命令：

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/labyrinth
```

旧入口也还能用（`game.py` 现在只是一个兼容壳，会转发到 `labyrinth.game.main`）：

```bash
python game.py
```

首次运行会在当前工作目录生成 `config.ini`。迷宫现在直接在内存里生成，
不再往 `maps/` 目录写 `.npy` / `.txt` 地图文件。

## 配置说明

`config.ini` 与旧版保持相同的节名和键名，老的配置文件可以直接继续用：

```ini
[Game Settings]
show_position = False
show_direction = False
show_head = False
```

| 配置项 | 作用 |
| --- | --- |
| `show_position` | 每回合显示当前位置坐标 |
| `show_direction` | 每回合显示当前朝向向量 |
| `show_head` | 每回合显示"头向"向量（左右转时的参考轴） |

三个开关默认都是 `False`。文件缺失时使用默认值并在启动时自动创建；
某个键缺失或写坏时会退回该键的默认值，不会让游戏起不来。

## 项目结构

```text
labyrinth/
├── __init__.py     版本号与包说明
├── __main__.py     python -m labyrinth 入口
```

## 开发与测试

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"    # 或仅装测试依赖：.venv/bin/pip install pytest
.venv/bin/python -m pytest -q
```

测试覆盖的关键点：

- 迷宫连通性：起点 `S` 一定能走到终点 `E`，所有道路属于同一连通分量；
- 边界：所有坐标都在 `[0, size)` 内，越界访问会报错；
- 尺寸语义：`shape == (size,) * dimensions`，格子数 `size ** dimensions`；
- 配置：保存/读取往返、旧版配置文件兼容、缺文件/缺键的容错；
- 指令：`w/a/d/s/q/e/h/r` 的合法解析、非法输入提示、二维世界禁用 a/d、
  转向到头顶/越界维度的提示，以及 s/q/e/a/d 的转向几何。

## 已知限制

- **偶数边长**的 DIY 迷宫会留下不可达区域。这是旧版 DFS「只沿坐标轴正方向每次走 2 格」
  的固有行为，为了保证玩法不变没有改成奇偶校验；
- 高维度 / 大边长是 `size ** dimensions` 级别，很容易耗尽内存和时间。
  DIY 输入上限 29 只是防呆，不是性能保证；
- 二维世界没有 a/d（与旧版相同的提示）；
- 纯终端文字界面，没有存档；
- 唯一一处刻意的可见行为变化：旧版把关卡存成文件后按文件名排序，导致难度 3 的
  `stage10` 会排在 `stage2` 前面；现在按难度表生成顺序游玩，关卡编号也统一成
  `stage1..stageN`。
